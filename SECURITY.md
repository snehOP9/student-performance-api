# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public issue.

Contact the repository maintainer privately through the contact information available on the maintainer's GitHub profile or portfolio.

Include:

- A clear description of the issue
- Steps to reproduce
- Potential impact
- Suggested mitigation, if known

Do not include real student records, passwords, tokens, API keys, or other sensitive data in a report.

## Scope

Security reports involving authentication, authorization, exposed secrets, unsafe API behavior, dependency vulnerabilities, or unintended access to student data are especially important.

Thank you for helping keep the project safe.
